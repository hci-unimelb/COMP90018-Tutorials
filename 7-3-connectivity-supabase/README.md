# Tutorial 7-3: Supabase Connectivity

Demonstrates the [Supabase Kotlin SDK](https://github.com/supabase-community/supabase-kt) for Android:

- **SELECT** all messages from a Supabase Postgres table on startup
- **INSERT** a new message when the user taps Send
- Manual **Refresh** button to reload the list

## Architecture

```
MainActivity
  └── SupabaseClientProvider  (singleton Supabase client)
        └── Postgrest plugin  (SQL queries via REST)

Message.kt  (@Serializable data class ↔ DB row)
```

All network calls are `suspend` functions running on `Dispatchers.IO` via `lifecycleScope.launch + withContext`.

---

## Supabase Setup

### 1. Create a project

Go to [supabase.com](https://supabase.com), sign in, and create a new project.

### 2. Create the `messages` table

Open **SQL Editor** in your Supabase dashboard and run:

```sql
-- Run this in Supabase SQL Editor (supabase.com > your project > SQL Editor)
CREATE TABLE messages (
    id         bigint generated by default as identity primary key,
    content    text not null,
    created_at timestamp with time zone default now()
);

-- Enable Row Level Security
ALTER TABLE messages ENABLE ROW LEVEL SECURITY;

-- Policy: allow all operations for tutorial purposes
-- In production you would restrict this based on auth.uid()
CREATE POLICY "tutorial_allow_all"
    ON messages
    FOR ALL
    USING (true)
    WITH CHECK (true);
```

### 3. Get your credentials

In your Supabase dashboard go to **Project Settings → API**:

- **Project URL** — looks like `https://xxxxxxxxxxxx.supabase.co`
- **Publishable key** (`sb_publishable_xxx`) — safe to embed in client apps

### 4. Configure `local.properties`

Add the following to `local.properties` in the **root** of this repo (the file is gitignored):

```properties
SUPABASE_URL=https://xxxxxxxxxxxx.supabase.co
SUPABASE_KEY=sb_publishable_xxxxxxxxxxxxxxxxxxxxxxxx
```

These values are injected into `BuildConfig` at compile time via `buildConfigField` in `build.gradle.kts`.

---

## Running the app

1. Complete the Supabase setup above.
2. Sync Gradle (`File → Sync Project with Gradle Files` in Android Studio).
3. Run on a device or emulator with API 33+.
4. Type a message and press **Send** — it will appear in your Supabase dashboard under Table Editor → messages.

## Key dependencies

| Library | Purpose |
|---|---|
| `io.github.jan-tennert.supabase:bom:3.1.4` | BOM that pins all supabase-kt versions |
| `io.github.jan-tennert.supabase:postgrest-kt` | Database CRUD via PostgREST |
| `io.ktor:ktor-client-android:3.1.0` | HTTP engine required by supabase-kt |
| `org.jetbrains.kotlin.plugin.serialization` | Enables `@Serializable` for data classes |

> **Note:** supabase-kt BOM 3.x requires Kotlin 2.0+. This module bumps the project Kotlin version from 1.9.24 to 2.0.21 in `gradle/libs.versions.toml` — this is backward-compatible with all other modules.
